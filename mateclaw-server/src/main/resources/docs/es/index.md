features:
  - icon: 🧑‍💼
    title: Empleados digitales, no chatbots
    details: Contratas colegas, no una caja de chat. Cada uno tiene un rol, un objetivo, una historia, un avatar pixel-art y un color propio — seis plantillas integradas listas para usar. ReAct + Plan-and-Execute, delegación paralela entre empleados.
  - icon: 🤝
    title: Equipos, no lobos solitarios
    details: Una solicitud de equipo se convierte en un Team Run: objetivo, DAG de tareas, ejecución de trabajadores, síntesis final y entregables permanecen juntos. Chat entrega resultados, Agentes observa el trabajo en vivo y Equipos gobierna el historial y las aprobaciones. En 2.1.0, una ronda de colaboración es un registro de trabajo completo.
  - icon: 🧩
    title: Las Skills son el esqueleto, no un plugin
    details: Un SKILL.md más un LESSONS.md que crece con el uso. Ocho plantillas iniciales, un asistente de creación de cinco pasos y verificaciones pre-vuelo antes de instalar. Puentes MCP y ACP — incluso Claude Code y Codex aparecen como empleados.
  - icon: 📚
    title: Conocimiento, con forma
    details: El LLM Wiki digiere archivos crudos en páginas estructuradas con resúmenes y backlinks. Una biblioteca que puedes leer, no un almacén de vectores que consultas. La caché activa se auto-inyecta en los prompts del sistema de tus empleados.
  - icon: 🧬
    title: Memoria que se acumula
    details: Contexto de sesión, extracción post-chat, archivos de workspace y consolidación programada tipo "Dreaming". La conversación de mañana empieza donde terminó la de hoy.
  - icon: 👀
    title: Ves lo que hace cada empleado
    details: La Consola de Runtime del Admin muestra quién está ejecutando, en qué paso está, cuántos tokens ha usado, con reciclaje forzado de un clic cuando se atasca. El streaming se muestra de forma honesta por etapas, la delegación multiagente ya no pelea consigo misma y las tareas largas exigen respuestas basadas en evidencia.
  - icon: 🔀
    title: Procesos de negocio, no traspasos manuales
    details: Los Workflows componen múltiples empleados más acciones del sistema (aprobaciones, despacho a canales, escritura de memoria) en un DSL lineal publicable, disparable y reproducible — siete modos de paso. Los Triggers conectan eventos del sistema a esos flujos — seis tipos de patrón cubren cron, webhooks, mensajes de canal, ciclo de vida de empleados, coincidencia de contenido y finalización de workflow.
  - icon: 🌐
    title: Toda superficie que importa
    details: Consola web, app de escritorio con JRE 21 incluido y ocho canales de chat. Mismo cerebro, misma memoria, dondequiera que trabaje tu equipo.
