# Changelog

Notas de release de cada versión de AuraClaw. La documentación más reciente siempre vive en `docs/en/` como la única fuente de verdad — estas notas tratan de lo que *cambió* en cada versión.

Para diffs históricos, revisa el git tag correspondiente. Para el "por qué" detrás de una feature, sigue el enlace a la nota de release completa.
