Genera según el formato JSON definido en el mensaje de sistema un resultado de enrutamiento que contenga **solo metadata**:
- `create`: conceptos nuevos sin página correspondiente, **solo slug + title + summary, sin escribir content**
- `update`: páginas existentes que deben actualizarse por fusión según este material, **solo un arreglo de strings de slugs**

No intentes generar ni fusionar cuerpos de página tú mismo — eso lo hacen llamadas LLM independientes de la siguiente fase. Tu salida debe mantenerse dentro de unos pocos KB.
